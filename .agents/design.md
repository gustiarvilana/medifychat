## Overview
Medify Chat utilizes the "Clinical Precision" design system, focusing on reliability, cognitive clarity, and efficient administration. The aesthetic is modern, minimalist, and built for high-density information display in healthcare contexts.

## Core Design Principles
1.  **Cognitive Ease:** Generous whitespace to reduce fatigue.
2.  **Authority:** Calm, professional color palette emphasizing trust.
3.  **Actionable Data:** Visual hierarchy directs focus to critical information.
4.  **Restraint:** Minimal decorative elements; utility-first design.

## Technical Specifications

### Colors
- **Primary (#3755c3):** Brand, primary actions, active navigation.
- **Secondary (#006c49):** Positive outcomes, online status.
- **Neutrals:** Professional grayscale for structural elements.
- **Surface (#f8f9ff):** Base background color.

### Typography
- **Font:** Inter
- **Usage:** 
  - **Metrics:** `display-lg` (36px, 700)
  - **Headlines:** `headline-lg` (28px, 600)
  - **Body Text:** `body-md` (16px, 400)
  - **Labels:** `label-caps` (12px, 700, uppercase)

### Spacing & Layout
- **Base Unit:** 8px.
- **Responsiveness:** Fluid grid system adapted for desktop, tablet, and mobile.

### Component Styling
- **Buttons:** 40px height for primary actions.
- **Forms:** Clean inputs with focus states to indicate interactivity.
- **Cards/Containers:** Soft edges (12px radius) and subtle elevation to define content blocks.

For detailed component-level specifications (buttons, inputs, tables), refer to the underlying "Clinical Precision" system.
